# Practical Linux Command Cookbook

> A practical collection of Linux command examples for developers, DevOps engineers, backend engineers, and system administrators.

This repository contains concise, real-world command examples for navigation, file management, networking, process management, permissions, compression, and shell scripting.

## Who Is This Repository For?

- Backend developers
- Java engineers
- DevOps engineers
- SRE engineers
- Linux beginners
- Students preparing for interviews
- Engineers working with servers and cloud environments

| Topic | Description |
|---|---|
| [Get help](0_get_help.sh) | Learn how to access Linux manuals, documentation, and command help pages |
| [Navigate directories](1_navigate_directories.sh) | Move efficiently through the Linux filesystem using common navigation commands |
| [List files](2_list_files.sh) | Display files and directories with sorting, hidden files, and human-readable sizes |
| [Creating, moving and removing files](3_creating_moving_and_removing_files.sh) | Create, rename, move, and remove files and directories |
| [Viewing file contents](4_viewing_file_contents.sh) | Read and inspect files directly from the terminal |
| [Editing files](5_editing_files.sh) | Edit files using terminal-based text editors such as Nano and Vim |
| [Search for pattern](6_search_for_pattern.sh) | Search files and directories using grep with recursive and advanced options |
| [Find files and directories](7_find_files_and_directories.sh) | Locate files and directories using different search criteria |
| [View running processes](8_view_running_processes.sh) | Monitor active processes and system activity in real time |
| [Kill processes](9_kill_processes.sh) | Stop processes using PID, process names, or pattern matching |
| [Check network configuration](10_check_network_configuration.sh) | Inspect network interfaces, IP addresses, and routing information |
| [Test network connectivity](11_test_network_connectivity.sh) | Verify connectivity and trace network routes to remote hosts |
| [Check disk usage](12_check_disk_usage.sh) | Analyze disk space usage for filesystems, directories, and files |
| [Change file permissions](13_change_file_permissions.sh) | Modify file and directory access permissions with chmod |

| [Redirect output to file](19_redirect_output_to_file.sh) | Redirect standard output and errors into files for logging and automation |
| [Pipes to combine commands](20_pipes_to_combine_commands.sh) | Chain commands together by passing output from one command into another |
